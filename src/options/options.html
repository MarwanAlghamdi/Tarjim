Ollama Arabic Translator

Accepts host:port or a full URL — e.g. 192.168.1.50:11434. Ollama and OpenAI-compatible servers (llama.cpp llama-server, LM Studio, vLLM) both work; which one it is is detected here. A server on another machine must be started with --host 0.0.0.0.

Keeps the model in VRAM so the first translation is not delayed by a cold load (measured at 24.5 s for gemma3:12b). Turn off to free VRAM between uses.
